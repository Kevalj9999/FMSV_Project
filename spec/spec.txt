FIFO System Specification:

1. On reset:
   - wr_ptr = 0
   - rd_ptr = 0
   - count = 0
   - full = 0
   - empty = 1

2. Write operation:
   - If wr_en == 1 and full == 0:
       wr_ptr increments
       count increments

3. Read operation:
   - If rd_en == 1 and empty == 0:
       rd_ptr increments
       data_out gets mem[rd_ptr]
       count decrements

4. Full condition:
   - full == 1 when count == 15

5. Empty condition:
   - empty == 1 when count == 0

6. Controller:
   - wr_en is 1 when not full
   - rd_en is 1 when not empty
